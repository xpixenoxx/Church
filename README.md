# Morph Ministries Church Website

A modern, responsive website for Morph Ministries church featuring service details, ministries, resources, worship information, community connect, and contact forms.

## Features
- **Hero & Mission**: Introduction and welcome to the congregation.
- **Service & Worship**: Details on Sunday and weekday services.
- **Ministries & Connect**: Ways to get involved and join community groups.
- **Resources**: Sermons, guides, and church materials.
- **Interactive Forms**: Get involved and contact forms.

## Getting Started
Open `index.html` in any modern web browser to view the website locally.
